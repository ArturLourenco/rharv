# Catchment (roof) areas of the IFPB-PI campus

Projected roof areas of the four buildings of the IFPB, Campus Princesa
Isabel, that can serve as rainwater catchment surfaces.

## Usage

``` r
areas_pi
```

## Format

A data frame with one row per building:

- block:

  Building name.

- area_m2:

  Projected roof area, in square metres (m2).

## Source

Vectorised aerial imagery of the IFPB, Campus Princesa Isabel.
