# Open the rharv demonstration notebook

Opens the bundled R Markdown demo (`rharv-demo.Rmd`), which exercises
every function, plot and dataset of the package, in your editor (RStudio
when run from an RStudio session). Use Knit to render it to HTML.

## Usage

``` r
rh_demo()
```

## Value

Invisibly, the path to the demo file.

## Examples

``` r
if (FALSE) { # \dontrun{
rh_demo()
} # }
```
